# ЗАДАНИЕ 5. ПОДКЛЮЧЕНИЕ РЕПОЗИТОРИЯ И ОРГАНИЗАЦИЯ РАБОТЫ С ВЕТКАМИ В XCODE

### Вопрос 1: Как создать локальный git-репозиторий для проектов в Xcode?
**Ответ:** Для создания локального git-репозитория в Xcode можно воспользоваться встроенной функцией. 
* При создании нового проекта в Xcode доступна опция **«Create Git repository on my Mac»**, которую можно отметить галочкой. 
* Если проект уже создан, его можно открыть, затем в верхнем меню выбрать `Source Control` -> `Create Git Repository…`, после чего Xcode автоматически инициализирует локальный репозиторий в каталоге проекта.

---

### Вопрос 2: Как добавить внешний репозиторий в Xcode? Назвать два способа подключения.
**Ответ:** 1. **Первый способ (Клонирование):** Использовать опцию клонирования репозитория при старте. Для этого в Xcode выбирают меню `Source Control` -> `Clone...`, затем указывают URL-адрес внешнего репозитория (например, с GitHub) и клонируют его в локальную директорию на компьютере.
2. **Второй способ (Связывание существующего):** Создать локальный репозиторий в Xcode, а затем через командную строку (Терминал) добавить удалённый репозиторий командой:
   ```bash
   git remote add origin <URL_адрес_репозитория>
После этого Xcode автоматически обнаружит связь с удалённым репозиторием.

Вопрос 3: Как создать ветку репозитория в Xcode?
Ответ: Для создания новой ветки в Xcode необходимо открыть меню Source Control (или использовать навигатор истории Repositories), затем выбрать опцию «New Branch…». Далее в появившемся диалоговом окне ввести название новой ветки и подтвердить создание. После этого Xcode автоматически переключится на созданную ветку, и все дальнейшие коммиты будут фиксироваться именно в ней.

Вопрос 4: Как отменить commit в Xcode?
Ответ: Отменить commit в Xcode можно с помощью встроенных инструментов работы с историей изменений:

Перейдите в Source Control -> Show History, найдите нужный коммит, нажмите на него правой кнопкой мыши и выберите опцию «Reset to Commit…» или «Discard Changes», чтобы вернуть репозиторий к предыдущему состоянию.

Если коммит еще не был отправлен на удалённый сервер (не был сделан Push), в меню можно использовать команду «Undo Last Commit».

Также это можно сделать через командную строку, выполнив команду:

Bash
git reset --soft HEAD^
Вопрос 5: Как слить ветки в Xcode?
Ответ: Для слияния веток в Xcode используется встроенная функция Merge:

Сначала необходимо переключиться на ту ветку, в которую планируется слияние (например, на основную ветку main).

Затем в меню Source Control выбрать пункт «Merge From Branch…» и указать ветку, изменения из которой нужно забрать (например, feature-task5).

Xcode выполнит слияние. Если в процессе возникнут конфликты кода, среда предложит разрешить их с помощью удобного графического встроенного инструмента для слияния (Merge Tool).
